# LavaPool

Плагин зон с наградами для Paper 1.21.4 и Java 21. Требуется LavaAPI 1.0.3 или новее с API версии 2.

[Скачать плагин](https://github.com/svarcovv/LavaPool/releases/latest)

Игрок получает награду за время внутри зоны. Доступны обычные и premium-зоны, пауза таймера, ограничение аккаунтов с одного IP и множитель выходного дня.

Таймер, вход и выход из зоны, награды и отказы в доступе отображаются в общем HUD LavaAPI. С LavaResurs используется оформление ресурспака, без него - читаемый текст. Параметр `actionBar` в messages.yml задаёт текст таймера.

Проверки игроков распределены по 20 тикам. Награды выдаются через очередь - по умолчанию до 4 команд за тик с бюджетом 2 мс. Одна команда стороннего плагина может занять больше бюджета; следующая начнётся в другом тике.

## Команды

| Команда | Действие |
| --- | --- |
| `/lavapool wand` | Выдать селектор зоны |
| `/lavapool create <имя> <free\|premium>` | Создать зону |
| `/lavapool remove <имя>` | Удалить зону |
| `/lavapool teleport <имя>` | Телепортироваться к зоне |
| `/lavapool reload` | Обновить конфиги и сбросить текущие таймеры |

Алиасы: `/wpool`, `/pool`. Команды reload и remove доступны из консоли.

## Права

- `lavapool.admin` - управление зонами, по умолчанию у операторов.
- `lavapool.type.premium` - доступ к premium-зонам.

## Награды

Настройки зон хранятся в `pools/*.yml`. В командах доступны `%player_name%`, `%player%` и `%money%`. При установленном PlaceholderAPI обрабатываются его плейсхолдеры.

`%money%` берёт `defaultReward` и учитывает `weekendMultiple` в субботу и воскресенье по времени сервера. Таймеры разных зон не смешиваются. При выходе с сервера прогресс сбрасывается.

`IPLimit` ограничивает число игроков с одного IP одновременно в зонах наград; 0 отключает лимит. Ответы команд наград скрыты при `performance.silentRewards: true`.
